АДМИН ПАНЕЛЬ PSKBT - КРАТКОЕ РУКОВОДСТВО
=========================================

✅ ЧТО СОЗДАНО:
• Полнофункциональная админ панель для управления сайтом
• Управление продуктами, категориями, технологиями, новостями
• Загрузка и управление изображениями
• Редактирование технических характеристик (A/B параметры)
• Session-based аутентификация с защитой

📍 ГДЕ НАХОДИТСЯ:
Админ панель: http://localhost:3000/admin
Код: /app/admin/, /components/admin/, /lib/auth.ts

🔐 УСТАНОВКА ПАРОЛЯ:
1. Откройте файл .env.local
2. Найдите строку: ADMIN_PASSWORD=change-me-to-strong-password
3. Замените на сложный пароль: ADMIN_PASSWORD=YourStr0ngP@ss123!

🚀 ЗАПУСК:
npm run dev
Откройте: http://localhost:3000/admin
Введите пароль → готово!

📋 ФУНКЦИИ:
✓ Добавление/редактирование/удаление продуктов
✓ Редактирование техспеков (A/B параметры)
✓ Управление категориями
✓ Загрузка изображений
✓ Управление технологиями и системами
✓ Управление новостями
✓ Все данные сохраняются в JSON

🎯 ПРИМЕРЫ:
• Добавить продукт: Нажать "Новый продукт" → заполнить форму → сохранить
• Загрузить изображение: Нажать область upload → выбрать файл → готово
• Редактировать новость: Нажать на новость → внести изменения → сохранить

⚠️ ВАЖНО:
- Используйте ОЧЕНЬ СЛОЖНЫЙ пароль!
- Периодически делайте резервные копии /data/
- На продакшене измените ADMIN_SESSION_SECRET
- Используйте HTTPS на боевом сервере
