# 🔐 Админ Панель - Руководство

## Доступ к админ панели

Админ панель доступна по адресу: **`http://localhost:3000/admin`** (или `https://yourdomain.ru/admin` на продакшене)

## Настройка доступа

### Установка пароля

Отредактируйте файл `.env.local` и установите сложный пароль:

```env
# Сложный пароль для входа (примеры)
ADMIN_PASSWORD=your-very-strong-password-12345!@#$%^&*

# Secret ключ для сессий (измените на случайный)
ADMIN_SESSION_SECRET=your-super-secret-session-key-change-this
```

**Важно:** Используйте **очень сложный пароль** с комбинацией букв, цифр и символов!

## Функции админ панели

### 📦 Управление продуктами

1. **Категории продуктов**
   - ➕ Добавлять новые категории
   - ✏️ Редактировать название, описание, изображение
   - 🗑️ Удалять категории

2. **Продукты**
   - ➕ Добавлять новые продукты
   - ✏️ Редактировать все параметры
   - 📊 Редактировать технические характеристики (в формате A/Б)
   - 📷 Загружать и заменять изображения
   - 🗑️ Удалять продукты

**Формат технических характеристик:**
```
Параметр: "внешний вид"
├─ А: "Жидкость коричневого цвета"
└─ Б: "Жидкость коричневого цвета"
```

### ⚙️ Управление технологиями

1. **Категории технологий**
   - Добавить/редактировать/удалить категории
   - Загружать фоновые изображения и иконки

2. **Системы**
   - Добавить/редактировать/удалить системы внутри категорий
   - Каждая система связана с категорией

### 📰 Управление новостями

1. **Новости**
   - Добавить новую новость
   - Редактировать название, описание, дату
   - Выбрать категорию (Продукт, События, Разработка)
   - Загружать изображение
   - Удалить новость

## 📸 Загрузка изображений

### Как работает загрузка?

1. Нажмите на область "📷 Выбрать изображение"
2. Выберите файл со своего компьютера
3. Изображение автоматически загрузится и сохранится в `/public/images/`

### Поддерживаемые форматы
- `JPG` / `JPEG`
- `PNG`
- `WebP`
- `GIF`

### Где сохраняются изображения?

```
/public/images/
├── products/          # Изображения продуктов
├── press/            # Изображения новостей
└── tech/             # Изображения технологий
```

## 🛡️ Безопасность

### Как работает аутентификация?

- **Метод:** Session-based (cookie)
- **Защита:** httpOnly cookies (невозможно украсть через JavaScript)
- **Срок сессии:** 7 дней
- **Шифрование:** iron-session (AES-256)

### Лучшие практики

1. ✅ Используйте **очень сложный пароль**
2. ✅ Меняйте `ADMIN_SESSION_SECRET` на случайное значение
3. ✅ Используйте **HTTPS** на продакшене
4. ✅ Регулярно меняйте пароль
5. ❌ Не делитесь паролем по Email
6. ❌ Не передавайте пароль через незащищённые каналы

## 📝 JSON структура и примеры

### Как редактировать технические характеристики?

В админ панели используется удобный интерфейс:

1. Нажмите "Добавить" для добавления новой характеристики
2. Введите название параметра (например, "Плотность")
3. Введите значения для вариантов А и Б
4. Нажмите "Сохранить"

### Примеры значений

```
Параметр: "Плотность при 20°С, г/см3"
├─ А: "0,9-1,0"
└─ Б: "1,0-1,1"

Параметр: "Внешний вид"
├─ А: "Жидкость коричневого цвета"
└─ Б: "Жидкость коричневого цвета"
```

## 🐛 Решение проблем

### Проблема: "Неверный пароль"
- Проверьте, правильно ли введён пароль
- Убедитесь, что в `.env.local` установлен правильный пароль
- Перезагрузите страницу и попробуйте снова

### Проблема: Изображение не загружается
- Проверьте, что размер файла меньше 10 MB
- Убедитесь, что это поддерживаемый формат (JPG, PNG, WebP)
- Проверьте, что директория `/public/images/` существует

### Проблема: Данные не сохраняются
- Проверьте консоль браузера (F12) на ошибки
- Убедитесь, что файлы JSON доступны для записи
- Проверьте права доступа к папке `/data/`

## 🚀 API endpoints

Админ панель использует следующие API endpoints:

```
POST   /admin/api/auth               # Логин / Выход
GET    /admin/api/auth               # Проверка аутентификации
GET    /admin/api/products           # Получить все продукты
POST   /admin/api/products           # Добавить/обновить/удалить продукт
GET    /admin/api/technologies       # Получить все технологии
POST   /admin/api/technologies       # Добавить/обновить/удалить технологию
GET    /admin/api/news               # Получить все новости
POST   /admin/api/news               # Добавить/обновить/удалить новость
POST   /admin/api/upload             # Загрузить изображение
DELETE /admin/api/upload             # Удалить изображение
```
